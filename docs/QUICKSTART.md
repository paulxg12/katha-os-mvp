# KathaOS MVP

Hackathon project: Voice-first cultural commerce engine.

## Quick Start

```bash
npm install
cp .env.example .env.local
# Fill in keys
npm run dev
```

## Tech
- Next.js 14 (App Router)
- Supabase (PostgreSQL + Storage)
- OpenAI GPT-4o (Structured Output)
- Tailwind CSS
- Zod validation
